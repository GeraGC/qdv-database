Darmon–Vonk data

This database accompanies the articles on the values of rigid meromorphic cocycles for p-arithmetic groups attached to quaternion algebras, after Darmon–Vonk. It holds the p-adic values J computed at real quadratic cycles, and the algebraic numbers they were recognized as. Every value can be copied as a line of Sage code that rebuilds it exactly.

New here? The help pages explain every column, filter and term. The recognitions are numerical evidence: a value is recognized when a relation holds to the stated number of p-adic digits. A held-out check and the agreement of independent methods are shown for each value.
